# Ảnh mô tả bộ thủ (tuỳ chọn)

Thả ảnh vào thư mục này để thay hình minh hoạ mặc định của bộ thủ.

- Tên file = số thứ tự bộ thủ (Khang Hi 1–214), 3 chữ số: `001.png` (一), `075.png` (木), `085.png` (水)…
- Định dạng: `.png`, `.jpg`, `.jpeg` hoặc `.webp`. Nên dùng ảnh vuông, khoảng 256×256.
- Bộ nào không có ảnh sẽ dùng hình minh hoạ có sẵn trong app.

Sau khi thêm ảnh, push lên GitHub để build lại APK.
